# Хто бере кермо?

Односторінкова інтерактивна карта того, як вірусний допис Джекоба Коксона ввійшов у вже наявну політичну розмову про правила для ШІ. Мова сторінки — українська; зріз джерел — **26 вересня 2026 року**.

## Як читати карту

1. Натиснути **«Прибрати допис Коксона»**. Документовані до його допису стратегія MIRI, кампанія FLI та анонс законопроєкту залишаться.
2. Натискати вузли, щоб порівняти заявлену мету, публічно зафіксовану дію й межу доказу.
3. Зіставити три різні пропозиції: широка тимчасова пауза й державний регулятор, заборона ASI без широкої паузи, координований темп розробки з зовнішніми оцінювачами.
4. У розділі «Ресурс» розвести анонсовану стелю витрат, зареєстровані видатки на лобізм, внутріорганізаційний зв’язок і невідомий рахунок за конкретний медійний епізод.

Лінії між вузлами показують тільки зв’язки, для яких є оприлюднене джерело. Вони **не означають** прихованої змови, замовлення допису чи винагороди законодавцям. Посилання на першоджерела розміщено в картках вузлів і наприкінці сторінки. Пояснення Соареса є його публічним свідченням; без контракту воно не доводить оплати послуги.
